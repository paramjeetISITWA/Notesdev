Getting Started

Welcome to OpenBun Notes — a modern, fast, and intuitive note-taking application designed to help you capture, organize, and share your thoughts effortlessly. Built with Tiptap and powered by Arweave for decentralized, permanent storage.

Integrate it by using the Tiptap UI Components docs or our CLI tool.

npx @tiptap/cli init

Key Features

A fully responsive rich text editor with built-in support for formatting, markdown, keyboard shortcuts (⌘+B, ⌘+I), and advanced customization to make your writing more engaging and professional.

  • ✓ Rich Text Editing — Full markdown support with formatting tools
  • ✓ Decentralized Storage — Permanent storage on Arweave blockchain
  • ✓ Document Versioning — Track changes with full version history
  • ✓ Password Protection — Secure your sensitive notes
  • ✓ Image Support — Upload and embed images directly
  • ✓ Solana Integration — Connect with your Solana wallet seamlessly

How Data Gets Published on Arweave

When you save a note in OpenBun Notes, it is securely uploaded to the Arweave network through Bundlr. Arweave ensures your data is stored permanently, censorship-resistant, and distributed globally across thousands of nodes for maximum availability and security.

→

Instant Upload

Your note is encrypted and uploaded to Arweave's permaweb instantly.

→

Global Replication

Data is replicated across distributed nodes worldwide for 99.99% uptime.

→

Permanent Access

Within seconds to minutes, your note becomes accessible worldwide using a unique Transaction ID.
